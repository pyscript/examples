# dc.js - Dimensional Charting Javascript Library

[**dc.js**](https://dc-js.github.io/dc.js/) s a javascript charting library with
native  [crossfilter](http://crossfilter.github.io/crossfilter/) support, 
allowing highly efficient exploration on large multi-dimensional datasets 
(inspired by crossfilter's demo). It leverages  [d3](http://d3js.org/) to 
render charts in CSS-friendly SVG format. Charts rendered using dc.js are 
data driven and reactive and therefore provide instant feedback to user 
interaction. 


## Libraries Used

- [dc.js](https://dc-js.github.io/dc.js/docs/html/)
- [crossfilter](https://github.com/crossfilter/crossfilter/wiki/API-Reference)
- [D3](https://d3js.org/api)
